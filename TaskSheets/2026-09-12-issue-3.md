# Issue #3: System Prompt設定機能を追加する

- 日付: 2026-09-12
- ステータス: 実装完了、PR作成待ち

## 目的

`SettingsDialog.tsx` からカスタムsystem promptを設定できるようにし、
チャット送信時にOllamaへのメッセージ列の先頭(`role: "system"`)に
含めるようにする。

## やったこと

- `frontend-tauri/src/components/ui/textarea.tsx` を新設(既存の
  `input.tsx` と同じ流儀のshadcn風Textareaコンポーネント)
- `SettingsDialog.tsx` に System Prompt 用のテキストエリアを追加。
  既存の `settings` テーブルに `system_prompt` キーで保存・読込する
  (GitHub Token / Rakuten App ID と同じパターン)
- `App.tsx` の `sendMessage()` で `system_prompt` を読み込み、設定されて
  いれば長期記憶(`memories`)の system メッセージより前に別の system
  メッセージとして追加する。両方設定時は2つのsystemメッセージが
  自然に共存する。未設定時は従来通りsystem promptなし
- `npm run build` / `cargo build` とも成功を確認

## 次にやること

- 人間がcompare URLからPRを作成し、`npm run dev:app` で実機確認
  (system prompt入力→保存→チャットで口調等が反映されるか)を行う
